# 战网地区切换工具

Windows 11 / x64 的便携启动工具，使用已有的同一套战网启动国服或国际服亚洲登录入口。版本 0.2.0，初步验证版。

作者：[dff652](https://github.com/dff652)。界面底部提供作者主页链接。

## 使用

1. 正常退出游戏，并在战网菜单选择“退出”。如有更新任务，等待完成或通过战网自身的退出确认暂停。
2. 需要国际服网络加速时，先自行启动和配置已有的加速器。
3. 双击发布包中的 `BattleNetRegionSwitcher.exe`。无需管理员权限或另装 .NET。
4. 确认启动路径，选择“启动国服”或“启动国际服 · 亚洲”。
5. 在战网中确认登录入口，使用对应账号登录；游戏自己的区服需要另外确认。

检测到战网、Agent、常见游戏或临时更新进程仍运行时，工具会阻止启动。Agent 可能在退出战网后短暂驻留；等待它退出后再试。不会强制结束这些进程。无法确认进程状态时也会停止启动。游戏进程名称列表不可能覆盖所有游戏，请在使用前自行确认游戏和更新任务已结束。

## 实现和限制

- 国服参数：`--setregion=CN`；国际服亚洲参数：`--setregion=TW`。
- 参数来自社区用法，未找到官方稳定接口保证。已观察版本 2.52.12.17821 从 CN 切为配置中的 KR，并成功登录国际服。KR 是本次客户端记录的值，不代表任意游戏已选择韩国或台湾服务器。
- 第一版要求用户正常退出战网后再启动目标地区，不提供强杀或自动点击账号登录。
- 本工具不修改战网配置文件、账号归属、语言、游戏文件、网络代理、VPN、DNS 或系统路由。
- 不采集或保存密码、验证码、登录令牌、好友列表；不提供加速服务。
- 启动请求成功不代表账号登录成功、游戏区服正确或新闻商城已加载。
- 客户端更新可能改变参数行为，更新后应重新确认两个入口。
- 此版本未签名，尚待完成“国际服 → 国服 → 国际服”的用户账号及游戏验收。

工具设置位于 `%LOCALAPPDATA%\BattleNetRegionSwitcher\settings.json`，仅包含启动路径和上次请求地区。若不再使用，可关闭工具并移走发布包；战网自身的登录地区可能保留最后一次选择，可用相应地区启动参数或客户端提供的地区选项恢复。

## 调试日志

界面直接显示工具自身的调试日志，包括时间、INFO/WARN/ERROR 级别、请求地区、路径验证结果、进程阻止原因和启动结果。支持“复制日志”“打开日志目录”“清空视图”。清空视图不删除磁盘日志。

日志文件为 `%LOCALAPPDATA%\BattleNetRegionSwitcher\debug.log`，约 256 KiB 后轮转到 `debug.previous.log`；界面仅保留最近约 300 行。日志不会上传，也不采集战网原始日志、账号、密码、验证码或登录令牌，不记录完整安装路径。异常只记录类型，不记录原始异常消息。设置和日志不纳入 Git 仓库。

## 不用工具也可以切换

正常退出战网后，用对应地区参数启动同一程序即可。工具只是把启动入口、路径选择和运行状态检查集中在一个界面。示例：

```text
"C:\Program Files (x86)\Battle.net\Battle.net Launcher.exe" --setregion=CN
"C:\Program Files (x86)\Battle.net\Battle.net Launcher.exe" --setregion=TW
```

账号登录失败、新闻或商城加载失败需要单独排查。先比较同一内容在浏览器中能否打开，再对比网络加速设置；不要把参数切换当作网络修复。

## 本地编译

安装 .NET 10 SDK（本项目记录版本 10.0.401），在项目目录运行：

```powershell
./scripts/build.ps1 -Publish
```

如果 SDK 没有加入 PATH：

```powershell
./scripts/build.ps1 -DotnetPath '实际SDK目录\dotnet.exe' -Publish
```

发布结果为 `artifacts/win-x64/`，其中 EXE 自带运行环境。源码和运行环境分开存放。
