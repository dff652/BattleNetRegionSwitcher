# 战网地区切换工具：便携版使用说明

版本：0.3.0（初步验证版） · 作者：[dff652](https://github.com/dff652)

## 运行条件

- Windows 11 x64、已安装的战网客户端。
- 对应地区的账号和可用网络。需要加速时，先自行配置加速器。
- 解压运行包。`BattleNetRegionSwitcher.exe` 已包含 .NET 运行环境，无需安装本工具或另装 .NET；本工具本身不请求管理员权限。

当前 EXE 没有代码签名，Windows 可能显示来源提示。请核对下载来源。

## 开始使用

1. 正常退出游戏和战网。如有更新，先等待完成或通过战网自身的退出确认暂停。
2. 双击 `BattleNetRegionSwitcher.exe`。
3. 工具会自动核验已保存的启动路径，再查找常见安装目录和注册表；旧路径失效时会重新查找。仍未找到才需用“选择文件”定位 `Battle.net Launcher.exe` 或 `Battle.net.exe`。
4. 点击“启动国服”或“启动国际服 · 亚洲”。
5. 在战网中核对入口并自行登录，在游戏页面确认具体区服。

提示“已发送战网启动请求”只表示程序启动请求已发出，不代表登录或地区切换已经成功。工具不会迁移账号、角色、购买内容，也不提供网络加速。

## 运行状态与等待切换

上方状态区每 2 秒检查战网、Agent、已知游戏和可能的临时更新进程。“未检测到已知游戏进程”不保证所有游戏均已退出；Agent 运行也不等于一定正在下载。

“登录入口参考”来自战网配置的上次地区记录，显示文件记录时间。它不代表当前登录结果，也不是游戏区服；记录过时或格式不受支持时请以战网为准。“上次请求”则只表示本工具曾请求过哪个入口。

要先选地区、再退出战网：

1. 勾选“等待战网及相关进程退出后启动”，点击目标入口。
2. 在战网菜单自行选择“退出”，正常结束游戏；有更新时通过客户端处理。
3. 工具显示剩余秒数，最多等待 2 分钟；所有受检查进程退出后，再次检查并发送一次启动请求。
4. 点“取消等待”或关闭工具，可取消尚未发出的请求；超时会结束等待，需要重新点击才会再试。

等待默认不勾选，不会自动关闭或杀死任何进程；对已经发出的启动请求，取消按钮不会撤回它。

## 常见问题与日志

- **提示程序正在运行：** 正常退出所提示的游戏或战网后重试。只剩 Agent 时，等待其正常结束；工具不会强杀进程。
- **找不到战网：** 手动选择实际安装目录中的启动程序。本工具不包含战网安装包。
- **登录成功，新闻或商城却失败：** 在浏览器中对比打开对应页面，并检查网络或加速范围；这与启动请求是否发出是不同的问题。
- **需要反馈：** 展开调试日志后使用“复制日志”，附上版本、复现步骤和实际结果。不要发送密码、验证码、令牌或原始战网配置。

日志每次打开工具时默认收起，后台持续记录。点击“展开调试日志”查看；失败时可点结果区的“查看详情”，窗口不会自动展开。“打开日志目录”可查看日志文件；“清空视图”只清空窗口显示，不删除文件。

## 本机数据与移除

首次运行后，解压文件夹的常见结构如下：

```text
BattleNetRegionSwitcher/
├─ BattleNetRegionSwitcher.exe
├─ 使用说明.md
└─ logs/
   ├─ debug.log
   └─ debug.previous.log（日志轮转后出现）
```

- 日志默认位于 EXE 旁的 `logs`，约 256 KiB 后轮转；不依赖从哪个文件夹启动程序。
- 如果程序目录不可写，启动时自动改用 `%LOCALAPPDATA%\BattleNetRegionSwitcher\logs`，展开后标为“用户目录 / logs（备用）”。两处均不可写时，只保留窗口日志供复制。
- 设置仍保存在 `%LOCALAPPDATA%\BattleNetRegionSwitcher\settings.json`，内容为启动路径和上次请求地区。

某些启动环境会重定向用户数据目录。“打开日志目录”会打开本次实际写入位置，以按钮打开的目录为准。旧版日志留在原位置，不自动迁移。

日志不会自动上传。复制日志会写入系统剪贴板。单文件运行时也可能解压内置组件，因此“免安装”不等于“零残留”。

地区参考只读战网配置中的已知地区字段；不修改配置、不保存或上传原始内容。不读取账号密码来代替登录。

停止使用时，退出本工具后可删除解压目录。如还要移除偏好与日志，可自行删除本工具的数据目录（如有重定向，先通过按钮确认实际位置）；不要删除战网或游戏目录。

## 分享与当前限制

可以分享原始便携 ZIP，包内只有 EXE 和使用说明，运行后才生成 `logs`。对方解压后运行 EXE，并满足上述条件；自定义战网安装路径可能需要重新选择。重新打包时无需包含自己的运行日志。
