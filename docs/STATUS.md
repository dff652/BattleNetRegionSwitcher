## 接下来的顺序

1. **完成真实客户端往返验收。** 按 [验证清单](./VALIDATION.md#手工验收清单) 测试国服、国际服及目标游戏。用户自行登录，工具不接管账号或网络配置。
2. **补充兼容性证据。** 检查 Agent 等待、战网更新、不同安装路径、另一台 Windows 11 x64 和显示缩放。
3. **记录并修复实际发现的问题。** 修正影响启动或界面的缺陷；涉及逻辑变更时运行相关测试，更新验证记录。
4. **准备正式下载入口。** 验收后整理版本说明、便携 ZIP 和 SHA-256，再创建 GitHub Release。当前仍通过 Actions 提供临时构建产物，尚无 Release。

国际服新闻和商城加载失败需要单独排查网络；该问题的原因目前未确定，不以清理缓存或改变 VPN 设置作为默认处理。
