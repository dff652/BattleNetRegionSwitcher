## 真实客户端观察

验证环境为 Windows 11 x64，战网启动器更新后版本为 `2.52.12.17821`，Blizzard 数字签名有效。以下启动参数观察早于完整工具往返验收，不能据此宣称工具已经完成全部切换测试。

| 场景 | 观察 | 不能由此推出的结论 |
| --- | --- | --- |
| CN 参数启动 | 原配置已经是 CN，启动后自动登录国服 | 不能单独证明从国际服切回国服成功 |
| 正常退出后以 TW 参数启动 | 登录地区字段由 CN 变为 KR，日志出现国际站账号域名 | KR 不证明具体游戏选中了韩国或台湾服务器 |
| 国际服登录 | 曾出现 `BLZBNTBNA00000A8E (2400)`；用户保持 VPN 开启并启动 AK 加速器后，截图确认国际服登录成功 | 没有网络对照实验，不能认定 VPN 是根因或必须关闭 |

登录由用户自行完成。没有自动输入账号密码，也没有通过工具修改网络设置。

## 内容加载问题

曾观察到 `BLZBNTBNA000007D0 (2404)`，新闻、商城或游戏内容页加载失败。此问题与账号登录失败分开记录。

账号服务、游戏服务和网页内容可能出现不同的连接结果。独立网页请求不带客户端账号会话，也不一定与客户端内嵌浏览器走相同网络路径，不能替代客户端实测。

待对照：普通游戏页面是否正常、错误页“在浏览器中打开”的结果，以及加速器覆盖范围与网络组合。目前根因未确认。

## 手工验收清单

前提：由用户在客户端中完成登录；先确认游戏已退出、更新已完成或经客户端正常暂停。不要为测试强行终止更新进程。

- [ ] 使用同一份便携包，完成“国际服 → 国服 → 国际服”往返；每次记录请求地区、实际入口和登录结果。
- [ ] 在对应入口确认目标游戏账号与区服，再验证目标游戏能否正常启动。
- [ ] 验证仅剩 Agent 时工具会阻止启动；Agent 正常结束后能够再次请求启动。
- [ ] 验证战网正常退出、冷启动以及客户端更新后的参数兼容性。
- [ ] 单独复测国际服新闻与商城页面，不把内容页故障自动归因于地区切换。
- [ ] 在另一台 Windows 11 x64、未额外安装 .NET 的电脑上解压运行，并验证手动选择安装路径。
- [ ] 检查常用显示缩放比例下的窗口布局、按钮与日志可读性。

验收记录可包含日期、工具版本、战网版本、系统架构、操作步骤、预期与实际结果；不要提交账号、令牌、好友列表或原始战网配置。

代码编译与隔离测试通过，不等于以上真实客户端验收已完成。
